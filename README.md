# Deforestation_analysis_ML
   Deforestation Issue Analysis using Support Vector Machine (SVM) — exploring environmental, economic, and social factors driving forest loss.
This repository contains an end-to-end machine learning project analyzing global deforestation trends using Support Vector Machine (SVM). The dataset (deforestation_dataset.csv) includes variables such as tree cover loss, CO2 emissions, rainfall, population, GDP, and policy strictness.

The project workflow covers:

Data Preprocessing: Cleaning, encoding categorical variables, feature scaling, and train-test split.

Model Building: Training SVM models with linear, polynomial, and RBF kernels.

Evaluation: Performance metrics (MAE, MSE, RMSE, R²) and hyperparameter tuning with cross-validation.

Feature Analysis: Identifying key contributors like GDP, rainfall, and policy strictness.

Reporting: Visualizations (scatter plots, bar charts, heatmaps) and actionable recommendations for deforestation mitigation.

Deliverables:

Jupyter Notebook/Python script with the full SVM pipeline.

Comprehensive report with insights, visualizations, and recommendations.

This project demonstrates how machine learning can be applied to environmental issues, offering data-driven insights into deforestation causes and potential mitigation strategies.
